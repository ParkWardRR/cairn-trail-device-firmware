**The first Cairn trail device firmware: a capture logger for the LILYGO T-Beam Supreme.**

Every sensor on the board, each to its own CSV file in a new session directory on the SD card, with
the LoRa radio held off. This is T1's bring-up tool, not Cairn's sealed record — nothing here is
encrypted or signed; `format/v3` replaces the CSV files in T2.

### What it records

| File | Rate | |
|---|---|---|
| `GNSS.CSV` | 1 Hz | u-blox MAX-M10S UBX-NAV-PVT: time, fix, position, altitude, accuracy, velocity, heading, DOP |
| `SAT.CSV` | every 5 s | UBX-NAV-SAT, every satellite: constellation, C/N0, elevation, azimuth, used, health |
| `IMU.CSV` | 50 Hz | QMI8658 accelerometer (±8 g), gyroscope (±512 °/s), temperature |
| `BARO.CSV` | 4 Hz | BME280 pressure, temperature, humidity; elevation anchored to GNSS, climb and descent |
| `MAG.CSV` | 10 Hz | QMC6309 / QMC6310 raw field and uncalibrated heading |
| `POWER.CSV` | every 5 s | AXP2101 battery, USB, system voltage, charge state, fuel gauge, rail states |
| `PPS.CSV` | 1 Hz | GNSS time pulse against the monotonic clock (once there is a fix) |
| `EVENTS.CSV` | — | boot identity, rails, RTC, sensor init, SD layout, GNSS configuration, fixes, marks, buttons, errors |

BOOT marks the spot; PWR or a long BOOT press toggles the display; a USB console (`stat`, `ls`,
`cat` with CRC-32, `flush`, `stop`/`start`, `mark`, `reboot`) reads the card without removing it.
Cards formatted by macOS Disk Utility's default GUID scheme work as they are.

### Files

- `cairn-trail-0.1.0-<commit>-release.bin` — merged image (bootloader, partition table, app):
  `esptool --chip esp32s3 write-flash 0x0 <file>`
- `…-verbose.bin` — the debug build: every record echoed, register diagnostics, display always on
- `.elf` files with symbols for both, and `SHA256SUMS`

### Verified

On the owner's unit (V3.1 carrier, ESP32-S3 rev 0.2, MAX-M10S SPG 5.10), indoors on USB: the verbose
and the release build each recorded a session; every file was pulled back over USB with a matching
CRC-32; `scripts/verify.py --stationary` passed every check — GNSS at 1.00 Hz, IMU at 50.0 Hz
averaging ~1 g at rest, barometer at 4.00 Hz with elevation steady to under a metre, magnetometer at
~10 Hz, power every 5 s with the LoRa rail off in every row. The display, the BOOT mark and the PWR
display toggle were checked by eye.

**Not yet proven:** a GNSS fix (no sky indoors) and with it PPS, the RTC correction and the
elevation anchoring; battery operation; long runs. A `cat` over the console pauses logging while it
streams.

Built and released with local CI/CD only (`scripts/ci.sh`, `scripts/release.sh`). Rust on `esp-hal`
1.2 and Embassy. Details: [docs/firmware.md](https://github.com/ParkWardRR/cairn-trail-device-firmware/blob/main/docs/firmware.md).
